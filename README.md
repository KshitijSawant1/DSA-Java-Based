# 📘 Java DSA Operations Collection

A robust and well-organized collection of core **Data Structures and Algorithms (DSA)** implemented in Java. This repository is designed as a one-stop resource for learners and developers to **understand, apply, and master** essential DSA concepts through hands-on Java programs.

Whether you're preparing for coding interviews, teaching DSA concepts, or building academic projects — this collection provides concise, real-world implementations for each structure and algorithm.

---

## 🔍 Overview

This project contains modular, standalone `.java` programs demonstrating:

* Linear & Non-linear Data Structures
* Recursive & Iterative Algorithms
* Graph Traversals
* Hashing & Memory-efficient storage
* Real-world simulations like Voting Systems

---

## 📁 File-wise Breakdown

| File Name                | Description                                                                |
| ------------------------ | -------------------------------------------------------------------------- |
| `BTreeOPS.java`          | Binary Tree operations including creation, insertion, and traversals.      |
| `BinarySearchTree.java`  | Full Binary Search Tree implementation with insert, search, and delete.    |
| `BinomialHeapDemo.java`  | Demonstrates binomial heap operations: merge, insertion, and extraction.   |
| `CircularQueueOps.java`  | Circular Queue implementation using arrays.                                |
| `DFSGraphTraversal.java` | Depth-First Search traversal over adjacency lists or matrices.             |
| `DFSOps.java`            | General-purpose DFS logic in recursive style.                              |
| `ElectionOps.java`       | Simulates an election system using arrays and control structures.          |
| `HashingDemo.java`       | Demonstration of basic hashing with collision handling.                    |
| `LinkedListOps.java`     | Basic singly linked list operations.                                       |
| `LinkedListOps2.java`    | Enhanced version of linked list with extended features like reverse, sort. |
| `QueueOps.java`          | Standard Queue operations implementation.                                  |
| `StackOps.java`          | Stack using arrays with push, pop, and peek operations.                    |
| `VotingSystem.java`      | Real-world voting system using DSA concepts.                               |

## 🛠 How to Run

1. **Clone the repository**

   ```bash
   git clone https://github.com/your-username/Java-DSA-Ops.git
   ```

2. **Navigate to the directory**

   ```bash
   cd Java-DSA-Ops
   ```

3. **Compile and Run any file**

   ```bash
   javac FileName.java
   java FileName
   ```
